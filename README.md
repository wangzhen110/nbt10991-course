### 跨设备无缝同步

进度保存在浏览器 localStorage（同源隔离），**不会自动跨设备**。换设备时请：

1. 旧设备：进入任意视图 → 侧栏「导出 / 导入进度」或移动端「进度同步」→ 点「导出进度」得到一个 JSON 文件。
2. 通过任意方式（微信传文件 / 网盘 / 邮件）把它发到新设备。
3. 新设备打开本地单文件版或在线版 → 同样入口点「导入进度」→ 选择该 JSON 文件 → 进度合并（已答记录叠加，错题保留）。

## 怎么用

1. **讲解模式**（左侧导航切换）：每章 3~6 屏图文讲解，可「自动播放」逐屏推进；点「语音讲解」后由浏览器朗读当前屏内容（Chrome / Edge 支持中文），边听边学。
2. **答题模式**：选完选项立即判定，**答对答错都会显示解析与出处**。支持按章节 / 题型 / 范围（未作答、错题、已答对）筛选，可随机打乱，支持 1~6 数字键选选项、回车下一题。
3. **填空巩固**：85 道关键数值/概念填空，输入后立即判分并显示解析与出处。
4. **统计模式**：总正确率、各章掌握度、错题清单（可点击直接跳回该题）。

答题记录保存在浏览器本地（localStorage），关闭不丢失；「清空学习记录」可重置。

## 出处说明

每道题的「出处」字段精确到**条款号 / 表号 / 附录**，例如：

- `5.4.3.3`（手动下降速度）
- `表3`（检验项目：△必检 / —不作规定 / ※供需协商）
- `附录A 离心式安全锁锁绳速度`
- `5.3.2.2；3.8`（跨条款对照题）

点出处可弹出课程内知识库（对应条款原文），点解析中的规范号可查看该标准的名称。

解析部分不只给出答案，而是说明**为什么**：写明判定依据、易混淆点对照（如动 1.25 / 静 1.5 / 极限 3.5 倍载荷、20%~166% 手动下降速度、9→30 / 18、22→42 m/min 启锁速度等），以及与其他条款的关联。

## 几点说明

- 题库严格依据 PDF 原文（报批稿，封面标准号为占位「NB/T XXXXX—202X」）编写，未引入外部推测内容；标准中个别排版笔误（如条款 5.4.6.3 原文误作 5.3.6.3、表2「锌洛涂层」应为「锌铬涂层」）在知识库中以标注形式说明。
- 讲解幻灯片是对标准条款的**提炼**，不能替代标准原文，涉及设计、检验结论时仍须以标准正式文本为准。
- 修改题库后请同步重建单文件版：运行 `_verify\build_single_file.js`（node）。
